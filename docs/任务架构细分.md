## 3. 技术路线与验证墙点亮顺序

「四道门先行」——G0 第一步不是写玩法，而是把 `规则 → 编译 → 测试 → 数据可加载` 四门点亮全绿，之后功能每加一点立刻被门验收。

- 零第三方依赖（G0–G4）：stdlib `unittest` / `json` / `hashlib` / `compileall` / `ast`。理由：本机托管 Python 常缺包，验证墙必须随时能跑。
- G0-R 追加**第 0 道前置自检**：主动在 `python -O` 子进程投毒，证明显式校验未被优化模式剥离；四道门拒绝在优化模式下运行。
- G5 才引入 pygame；CI 中依赖缺失须优雅跳过、不破管（沿用项目所有者既有习惯）。
- 表现层只读状态，不回写世界；世界状态唯一入口是纯函数状态转移。
