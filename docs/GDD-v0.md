> 游戏开发专家交付物 v0：核心循环 / 世界结构 / 数值框架 / 原创溯源 / 合规自评。
> 状态：**原型级设计稿**；数值已于 **2026-11-15 22:02 由人裁定「先定稿」**（不再是契约验证用占位），平衡手感试玩复核作为非阻塞后续仍归人。对应 `docs/任务架构细分.md` 的 G0–G6。

## 1. 概念

一款 2D 俯视、桌面单机的原创生物收集与群岛探索游戏。世界由**手工固定的区域骨架**与**种子生成的区块内容**共同构成：地标与解锁顺序由人设计，每个区域内部的地形与遭遇由世界种子决定。

- 游戏内标题：**PokeWorld**（2026-11-14 门控裁定沿用仓库名；名称商标高风险由人明确接受。2026-11-15 22:02 人答「自己玩无所谓」→ **自用不上架、不做商标检索与近似风险评估**，风险由人接受；AI 不作法律判断。见第 6、7 节）
- 工程代号 / 仓库名：`PokeWorld`，与游戏内标题同名
- 生物统称：**潮灵 / Creature**；禁用「宝可梦 / Pokémon」等第三方词汇指称本项目资产
- **名称不构成授权**：作品名含 `Poke` 前缀，不代表可使用任何第三方 IP 的名称、角色、造型、音乐或数值表

## 2. 核心玩法循环

```
探索区块 → 触发遭遇 → 捕捉 / 回合对战 → 图鉴登记（记录「在哪抓」）
   → 获得能力门（冲浪 / 碎岩 / 怪力） → 解锁新区域 → 回到探索
```

- 收集感来自**出没条件**（地形 / 时段 / 能力门），而非编号递增。
- 图鉴里程碑按区域划分：首批 7 区域 × 约 8 潮灵，其中若干只在特定地形或夜间出现。
- 失败回流：战败返回最近地标，队伍状态保留，世界不重置（生成结果由 seed 重建）。

## 4. 数值框架（2026-11-15 22:02 已由人定稿）

- **基础值（5 项）**：体 / 力 / 守 / 敏 / 灵，取值 20–120；成长曲线按等级线性 + 个体修正（个体值亦由 seed 派生）。
- **属性（6 系，原创命名）**：潮汐 / 岩 / 林 / 焰 / 雷 / 霜；克制关系为 6×6 矩阵，存 `data/encounters.json`，代码中禁止硬编码。
- **伤害**（G2 返工 · `ADR-002` §2）：`dmg = max(min_damage, round(power × 克制倍率 × atk_scale / (1 + guard / guard_scale)))`；倍率只取 `type_chart`，`atk_scale / guard_scale / min_damage` 全部来自 `encounters.json::damage_formula`，代码零硬编码。8×8 实测范围 **6–48**、均值 18.4375、无触底组。
- **捕捉率**（S2-03 采纳后）：`p = clamp(base_catch × [catch_base + (1 - hp_ratio) × hp_weight] × 球倍率 × 状态倍率, min, max)`，`catch_base = 0.12` / `hp_weight = 0.88` / `min = 0.02` / `max = 0.95` 全部来自 `encounters.json::catch_formula`；球倍率来自 `items`、状态倍率来自 `statuses`（原单值 `ball_bonus` / `status_bonus` 已退场）。`balance_check.py` 十万次采样验证实际分布。
  - **S2-03 已解除（2026-11-15 22:02 人裁决「采纳」）**：原 hp 项 `(1 - hp_ratio)` 在满血时把倍率乘成 0、恒落下限 0.02；改带基数项后满血 c01 素织网 **0.0504** → 潮汐网+僵麻 **0.1542**（3.06 倍），道具与状态在满血场景生效。仅 c08 因 `base_catch × 0.12 < min` 仍落下限，属公式性质。设计见 `ADR-002` §5，机器事实见 `docs/平衡采样报告.md` §3。
- **道具 / 异常状态**（G2 返工 · `ADR-002` §4）：三档原创捕捉网（1.00 / 1.35 / 1.70）、两种状态道具（按 `apply_rate` 施加）、两种异常状态（昏沉 / 僵麻，带 `duration` 与 `counter_rate`）。动作 `item:<id>` 消耗背包道具；`step(state, action, rng)` 签名不变、状态全 frozen。
- **撤离**（G2 返工）：`p = clamp(flee.base_rate + 敏捷差 × agility_scale + 状态加成, min, max)`，不再恒成功；失败按状态的 `counter_rate` 判定反击。
- **遭遇权重**（G1-v3）：`w(cid) = terrain_weight × time_weight × region_pool × rarity[cid]`；同地形同种子结果一致。**2026-11-14 人裁决 S-02 口径仍成立**：`region_pool` 只是候选集合，`base_catch`（捕捉难度）**不参与遭遇权重**；新增的 `rarity` 是与之正交的独立维度。**2026-11-14 22:24 / 2026-11-15 人裁决**引入稀有度差异。权重为**相对量**，由 G2 按 `wᵢ/Σw` 加权抽样消费，不得当作概率直接比较；各区域实测比例 61.7/38.3 ~ 73.9/26.1。
- **经济**：无内购、无广告（原型级定位）；道具仅由探索与地标补给获得。

## 5. 平台与技术（假设 A1 / A2，待门控确认）
