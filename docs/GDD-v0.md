# GDD-v0：潮屿图鉴（Tide Atlas）设计大纲

> 游戏开发专家交付物 v0：核心循环 / 世界结构 / 数值框架 / 原创溯源 / 合规自评。
> 状态：**原型级设计稿**，数值均为契约验证用占位，待人确认。对应 `docs/任务架构细分.md` 的 G0–G6。

## 1. 概念

一款 2D 俯视、桌面单机的原创生物收集与群岛探索游戏。世界由**手工固定的区域骨架**与**种子生成的区块内容**共同构成：地标与解锁顺序由人设计，每个区域内部的地形与遭遇由世界种子决定。

- 游戏内标题（提案，待确认）：**潮屿图鉴 / Tide Atlas**
- 工程代号 / 仓库名：`PokeWorld`（用户指定；**不用于游戏内展示或商店页**，见第 6 节名称商标风险）
- 生物统称：**潮灵 / Creature**；禁用「宝可梦 / Pokémon」等第三方词汇指称本项目资产

## 2. 核心玩法循环

```
探索区块 → 触发遭遇 → 捕捉 / 回合对战 → 图鉴登记（记录「在哪抓」）
   → 获得能力门（冲浪 / 碎岩 / 怪力） → 解锁新区域 → 回到探索
```

- 收集感来自**出没条件**（地形 / 时段 / 能力门），而非编号递增。
- 图鉴里程碑按区域划分：首批 7 区域 × 约 8 潮灵，其中若干只在特定地形或夜间出现。
- 失败回流：战败返回最近地标，队伍状态保留，世界不重置（生成结果由 seed 重建）。

## 3. 世界结构（首批 7 区域 · 骨架层）

| # | 区域 | 地标 | 进入条件 |
|---|---|---|---|
| 1 | 汐湾镇 | 起始镇 / 图鉴领取 | — |
| 2 | 青草原 | 道馆 | — |
| 3 | 回声洞 | 碎岩试炼 | 需「碎岩」 |
| 4 | 灯塔港 | 补给 / 情报 | — |
| 5 | 碎浪群 | 沉船 | 需「冲浪」 |
| 6 | 灰火岛 | 火山道馆 | 需「怪力」 |
| 7 | 联盟 | 终局 | 集齐区域徽章 |

- 每区域内部切 4×4 区块，由 `rng(world_seed, region_id, cx, cy)` 决定地形。
- 区域之间**不做无缝加载**，用明确传送门连接；区块边界即状态边界（ADR-001）。

## 4. 数值框架（占位 · 契约验证用）

- **基础值（5 项）**：体 / 力 / 守 / 敏 / 灵，取值 20–120；成长曲线按等级线性 + 个体修正（个体值亦由 seed 派生）。
- **属性（6 系，原创命名）**：潮汐 / 岩 / 林 / 焰 / 雷 / 霜；克制关系为 6×6 矩阵，存 `data/encounters.json`，代码中禁止硬编码。
- **捕捉率**：`p = clamp(base_catch × (1 - hp_ratio) × ball_bonus × status_bonus, 0.02, 0.95)`；`balance_check.py` 十万次采样验证实际分布。
- **遭遇权重**：`w = terrain_weight × time_weight × region_pool`；同地形同种子结果一致。
- **经济**：无内购、无广告（原型级定位）；道具仅由探索与地标补给获得。

## 5. 平台与技术（假设 A1 / A2，待门控确认）

- 桌面单机 2D 俯视；Python 3.13 标准库（G0–G4），pygame 仅在 G5 作为首个第三方依赖引入。
- 存档只存 `world_seed + flags + 队伍状态`；区块生成结果不入库（不变量 #6）。
- 验证墙：`python tools/verify_all.py` 单命令四道门。
