## 设计要点（意图层，防后续被改坏）

- **单向数据流**：`输入 → Session.apply（唯一状态转移）→ frame_of（只读投影）→ window（只画）`；渲染层拿不到 `GameState` 的写入口，也不持有可变引用。
- **终点由拓扑派生**：唯一「无出边」区域即联盟，不写死 `r7`；能力名一律从 `World.abilities` / `edges[].requires` 读取，代码零能力名字面量（R3a / R3b）。
- **pygame 可选**：顶层零 import，`find_spec` 探测 + 环境变量模拟缺失；缺依赖时 CLI 降级 headless 并明确提示，验证墙不因第三方依赖破管。
- **存档是投影不是快照**：沿用 G4 三类字段白名单，文件 I/O 只在 `src/main.py`；生成结果仍由 `world_seed` 重建。
- **B 级归人**：键位手感、配色、窗口尺寸、中文显示效果只能由人试玩裁定，机器只证明「能画、能走、能存」。
