## 已知限制（如实登记，不抹去）

- **P1-01**：onefile 首次启动需解压到临时目录，有秒级延迟；体积 15.7 MB（Python 运行时 + pygame）。
- **P1-02**：Windows Defender 等可能对 PyInstaller 产物误报，需人对产物做信任判断（AI 不作安全承诺）。
- **P1-03**：存档写在 exe 同目录 `saves/`，该目录需可写；双击用户可在看得见处找到存档。
- **P1-04**：降级报告（仅 `POKEWORLD_NO_PYGAME=1` 触发）里的 `gate.ok=false`，因仓库级源码门 `gate.run()` 不随发行包运行（包内无 `src/`/`tools/` 源码副本）；**双击窗口路径不经过该报告**，其退出码恒为 0。游戏本体事实（session/atlas/save/manifest/golden）全绿，此布尔值不代表游戏缺陷。
- **P1-05**：观感仍是原型级（S7-02），打包不改变手感结论；仍归人的 B 级手感观感项。
- 继承未修缺口：S3-01/S3-02、S4-01~S4-05、S5-01~S5-07、S6-01~S6-03、S7-01~S7-03。
