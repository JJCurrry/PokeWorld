## 设计要点（意图层，防后续被改坏）

- **图鉴唯一事实源是「出没条件」**：登记项 `(cid, region, terrain, phase)` 由 `generate_chunk` 的 `terrain_counts` 主导地形与 `encounter_weights` 时段键机械派生；不按编号递增（GDD-v0 §2 / 术语表「图鉴 Atlas」）。
- **里程碑按区域、可反证**：`complete` 必须能由死端拓扑反证为 False，禁止写成恒真；r7 空 pool 的平凡达成要如实标注。
- **脚本是数据、解释器唯一**：`scripts.py` 只有字面量与只读匹配；任何 `Effect` 到状态的转换必须经 `game.apply_effects`，且不得触碰 `Progress` / `World`（G3 门控唯一入口是 `progress.step`）。
- **成长刻度只在 `evolution.py` 一处**：人 2026-11-16 明确选「代码常量 + ADR 登记」，它们是 G4 实现约定、非 A11 平衡数值；不得「顺手」写进三表，也不得散落到多个模块。
- **个体值走既有 `rng` 的 `stream` 隔离**：`stream="growth"` 与 `generate_chunk` 的 `stream="chunk"` 正交，零重拍快照。
- **存档是投影不是快照**：`to_save` 把 progress / atlas 压成排序去重的 `flags`，不存 `tick` / `log` / `blocked`，更不存任何生成结果。
- **纯函数形态沿用 G2 / G3**：frozen dataclass + `dataclasses.replace` 返回新对象；校验一律显式抛 `SchemaError` / `ValueError`（禁 `assert`）；模块级只放不可变字面量。
