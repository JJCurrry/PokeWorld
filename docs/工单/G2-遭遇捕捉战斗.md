## 设计要点（意图层，防后续被改坏）

- **`rng` 参数是不可变上下文，不是可变流对象**：`RngContext(world_seed, region_id, cx, cy, tick)` 为 frozen dataclass，`step` 内部按 `tick` 派生隔离流。若把 `Stream` 直接传进 `step`，游标推进会让「同参重跑」失去意义，纯度证明作废。
- **遭遇权重只决定「遇到谁」**：拆通道后同区域 pool 内各物种权重相同（均匀抽样），捕捉难度只影响 `catch` 动作。GDD §4 `region_pool` 本就是候选集合，不是稀有度表。
- **捕捉公式全部因子来自表**：`min` / `max` / `ball_bonus` / `status_bonus` 取 `encounters.json::catch_formula`，`base_catch` 取 `species.json`；`hp_ratio` 由状态里的当前 HP / 最大 HP 得出。
- **伤害公式是 AI 占位，非人已裁定数值**：采用「攻击力 × 克制倍率 − 防御的一半，至少 1 点」，只用 `base` 已有字段，不新增平衡数值；结构常数（`1` 保底、`2` 减半）**不属于 A11 已裁定范围**，待人复核。采样报告须明示此点。
- **采样是机器事实、平衡是人的判断**：`balance_check.py` 输出分布与区间，不写「手感良好」一类结论；结论在报告中留归人。
- **不变量 #4 的证明靠行为测试**：验证传入 state / tables 未被改、等价上下文结果一致、模块级只放不可变常量；不靠注释自称纯函数。
