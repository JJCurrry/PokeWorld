## 设计要点（意图层，防后续被改坏）

- **`rng` 参数是不可变上下文，不是可变流对象**：`RngContext(world_seed, region_id, cx, cy, tick)` 为 frozen dataclass，`step` 内部按 `tick` 派生隔离流。若把 `Stream` 直接传进 `step`，游标推进会让「同参重跑」失去意义，纯度证明作废。
- **遭遇权重只决定「遇到谁」**（G2 返工更新）：`w(cid) = 时段权重 × 区块地形均值 × rarity[cid]`；捕捉难度 `base_catch` **仍不参与遭遇**（人裁决 S-02 回归锁），只进 `catch` 动作。`rarity` 是与之正交的独立维度，改它会改快照但不改地形格 → 须人确认（R7）。
- **捕捉公式因子全来自表与状态**（2026-11-15 22:02 人裁决采纳 S2-03 后更新）：`p = clamp(base_catch × [catch_base + (1 - hp_ratio) × hp_weight] × 球倍率 × 状态倍率, min, max)`；`min` / `max` / `catch_base` / `hp_weight` 取 `catch_formula`，球倍率取 `items`、状态倍率取 `statuses`，`base_catch` 取 `species.json`；`hp_ratio` 由当前 HP / 最大 HP 得出。**hp 项带基数后满血不再是 0**，换网 / 上状态能拉开差距（见 `ADR-002` §5 / §8 与报告 §3）；四个结构常数全部入表，代码零硬编码。
- **伤害公式是表驱动的比例型**（G2 返工更新）：`max(min_damage, round(power × 克制 × atk_scale / (1 + guard / guard_scale)))`，`atk_scale` / `guard_scale` / `min_damage` 全部来自 `encounters.json::damage_formula`，**代码零硬编码结构常数**；数值已于 2026-11-15 22:02 由人裁定**定稿**。
- **道具 / 状态走动作字符串，不改 `step` 签名**：`item:<id>` 消耗背包道具，ball 类换装备网、status 类按 `apply_rate` 施加状态；每次回合动作后 `status_ticks` 递减、归零清除；捕捉未命中 / 撤离失败按 `counter_rate` 判定反击。状态与背包全部 frozen，用 `dataclasses.replace` 返回新对象。
- **采样是机器事实、平衡是人的判断**：`balance_check.py` 输出分布与区间，不写「手感良好」一类结论；结论在报告中留归人。
- **不变量 #4 的证明靠行为测试**：验证传入 state / tables 未被改、等价上下文结果一致、模块级只放不可变常量；不靠注释自称纯函数。
