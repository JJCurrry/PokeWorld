- ❌ 规则门用 AST 节点名精确匹配 → 动态导入 / 属性链 / 拼接漏检（F-15）。已加固到 14 个回归样例。

- ❌ R5 用「GDD 全文子串包含」核对溯源 → 正文任意位置写名字即可伪造（复评 R-03）。改为正则逐行解析 `| 潮灵 \`cNN\` 名称 |` 并比对名称。
