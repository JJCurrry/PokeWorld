## 踩坑与已试过且失败的方法

### G2 返工新增（2026-11-15）

- ⚠️ **满血时道具 / 状态全部失效**：`(1 - hp_ratio)=0` 把球倍率与状态倍率一并乘成 0，再被 `min` 抬回 0.02。实测「素织网/无」与「潮汐网/僵麻」理论值同为 0.020000。**这是公式性质不是 bug**，是否改带基数 hp 项归人（S2-03）；别以为建模已覆盖满血场景。
- ⚠️ **ADR 测算用名义 hp_ratio，实测用整数 HP**：半血 c01 名义 0.5 → ADR 算 0.643；实际 `22/45=0.4889` → 采样 0.656880。公式一致，别误判为实现偏差。
- ⚠️ 新增 `rarity` 会**改变 golden 快照内容但地形格逐格不变**；改生成器前先确认是否触发 R7，别事后「顺手重拍」。
- ⚠️ 把 `catch_probability` 的 `statused: bool` 直接换成两个 float 参数时，旧测试里 `True` 会被当成 1.0 而不报错——已改为显式 `ball_bonus` / `status_bonus` 并补表驱动用例。
- ⚠️ 测试里把 `catch_formula.min/max` 同时设成 0 会让所有概率被 clamp 抹平，比较倍率差异的用例会假失败；用真实表值 + 半血即可。
- ⚠️ **`verify_all.py` 现约 13–15 秒**（两次完整 23.5 万次采样 + 117 用例），不是挂死；给足超时，别误判死锁。
