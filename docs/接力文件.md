## 踩坑与已试过且失败的方法

### G5（2026-11-16 · 本次实施）

- ⚠️ **`chunk_grid(world, region)` 返回的是「区域有几个区块」（如 4×4），不是每区块的 8×8 地形格**；`frame_of` 画的 `grid` 来自 `generate_chunk(...)[tiles]`（`CHUNK_SIZE=8`），游标遍历的是区块网格。写测试时曾把两者混为一谈导致假红。
- ⚠️ **`topology.json` 的边字段是 `from` / `to`，不是 `source` / `target`**（`World.from_tables` 才把它凝固成 `Edge.source` / `Edge.target`）。直接读原始表时别套用 `World` 的属性名。
- ⚠️ **G4 存档是投影**：不持久化 NPC 访问记录，`is_complete` 若把「全 NPC 已访问」当硬条件，读档后永远无法通关。已改为投影可达的判定，主序列 7/7 NPC 由 `g5_report` 单独证明（S5-01）。
- ⚠️ **Git Bash 的 `/tmp` 与 Windows Python 的 `/tmp` 不是同一个路径**：shell 重定向写出的文件，Python 用 `open('/tmp/...')` 会 `FileNotFoundError`。跨解释器传 JSON 用管道读 `sys.stdin`，别用 `/tmp` 中转。
- ⚠️ **pygame 欢迎横幅会污染 CLI 的 JSON stdout**：`src/main.py` 开窗口前设 `PYGAME_HIDE_SUPPORT_PROMPT=1`；测试模块也要在 import pygame 前设 `SDL_VIDEODRIVER=dummy` / `SDL_AUDIODRIVER=dummy`。
- ⚠️ **给 `apply()` 加 `chunks_seen` 计数时误删 `new_state = replace(state, progress=moved)`**，触发 `UnboundLocalError`；修复后复跑全链。教训：在 `dataclasses.replace` 的赋值块里插入新字段时，先确认基础赋值还在。
- ⚠️ **「依赖缺失优雅跳过」必须在真实子进程里证**：`POKEWORLD_NO_PYGAME=1` 跑完整 `verify_all.py`，用 `skipped=9` vs `skipped=3` 的差值（6 = 窗口用例数）核对该跳的确实只跳了窗口用例，别靠注释自称。
