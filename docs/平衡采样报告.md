## 2. 基础捕捉率：实测 vs 公式理论值

公式（S2-03 采纳后，结构常数全部来自 `encounters.json::catch_formula`）：

```
p = clamp(base_catch × [catch_base + (1 - hp_ratio) × hp_weight]
          × 球倍率 × 状态倍率, min, max)
catch_base = 0.12    hp_weight = 0.88    min = 0.02    max = 0.95
```

基础行使用默认装备「素织网」(1.00) + 无状态，等价于两参数默认调用。
