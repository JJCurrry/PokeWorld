# ADR-008：双击可玩的发行包（发布工程，非 G8）

> 意图层记忆：为什么这样设计。一页纸：背景 / 决定 / 被否决的备选及原因 / 后果。
> 状态：**发布工程实施中**；边界：零改 G0–G7 已验收游戏逻辑、三表、`MANIFEST.sha256`、golden 快照。**这不是 G8 开工**：G8 仍待人明确授权并给方向，本 ADR 只把已验收成果做成可双击运行的交付物。

## 背景（Context）

G0–G7 已全部由人裁决验收通过，`python -m src.main --window` 可在装了 Python 3.13 + pygame 的机器上开窗试玩。但交付给「只想双击就玩」的人时有两个门槛：① 需要本机有 Python 与 pygame；② 需要知道命令行与工作目录。用户 2026-11-20 明确要求「做成双击就能玩的 .exe 或其他软件包」。本机 Python 3.13.14 + pygame 2.6.1 已装，PyInstaller 6.22.3 可安装。

约束：不借打包之名改任何受保护数据或已验收逻辑；`tools/gate.py` R6 要求新增含 `.py` 的目录必须登记扫描根，故新文件只能落在已登记的 `tools/` 下。

## 决定（Decision）

1. **发行形态**：PyInstaller **onefile** Windows exe（单文件，双击即玩），产物在 `dist/PokeWorld.exe`，不入库（`build/`、`dist/` 已在 `.gitignore`）。选 onefile 而非 onedir，是为了「双击一个文件」的交付直觉；代价是首次启动需解压到临时目录、体积较大。
2. **独立启动器**：新增 `tools/launcher.py`（在已登记扫描根内，受 R0–R6 约束），不修改 `src/main.py` 等任何已验收模块。冻结态把 `src.main.ROOT` 覆盖为 `sys._MEIPASS`（数据表解包位置），源码态退化为仓库根——因为 `src/main.py` 唯一读表点是 `main()` 内的 `schema.load_all(ROOT)`，覆盖模块级 `ROOT` 即可，无需碰源码。
3. **存档位置**：exe 同目录 `saves/slot1.json`（源码态为仓库根 `saves/`），双击用户能在看得见的地方找到存档；`--path` 显式注入，不依赖当前工作目录。仍沿用 G4 的三字段投影与 G5 的唯一文件 I/O 边界。
4. **资源打包**：`data/` 三表 + `MANIFEST.sha256` 以只读数据打进包内 `data/`；golden 快照与 `tests/` 不打进发行包。`hiddenimports` 通过 `collect_submodules("src")` 覆盖全部业务模块。
5. **构建可复现**：`tools/build_exe.py` 生成 spec 到 `build/`（gitignore 内），调用 `python -m PyInstaller`；不写死 Python 路径，用 `sys.executable`。

## 被否决的备选

- **改 `src/main.py` 支持 frozen 路径**：会动已验收模块，违反「零改 G0–G7 逻辑」；且 `ROOT` 在模块级用于 sys.path，改动面比覆盖模块变量大。
- **onedir 目录分发**：启动更快但交付是「一个文件夹 + exe」，不符合「双击一个文件」的直觉；如需可后续加 `--onedir` 选项。
- **双击 .bat 启动器**：依赖本机 Python/pygame，未消除用户门槛，不是自包含软件包。
- **Nuitka 编译**：未安装、编译链更重，onefile PyInstaller 已满足需求。

## 后果（Consequences）

- 正面：产物是自包含单文件 exe，双击即进窗口，无需 Python 环境；发布过程零改游戏逻辑 / 零改表 / 零重建清单 / 零重拍快照。
- 负面 / 已知限制：① onefile 首次启动有解压延迟；② exe 体积含 Python 运行时 + pygame；③ Windows Defender 等可能对 PyInstaller 产物误报，需人对产物做信任判断；④ 存档写在 exe 同目录，需该目录可写；⑤ 观感仍是原型级（S7-02），打包不改变手感结论，仍归人复核。
- 边界：**G8 未获开工授权**；本 ADR 不构成 G8 开工，不引入任何新玩法 / 新内容 / 平衡改动。
- 验证口径：exe 需实测 headless 通关、窗口冒烟渲染、存档读写；隔离验证「无本机 Python/pygame 也能跑」。
