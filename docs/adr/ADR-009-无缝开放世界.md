# ADR-009：无缝开放世界（G8）

> 意图层记忆。本 ADR **显式 supersede `ADR-001` §被否决「无缝连续大地图 / 流式加载」与「术语表·区块」中"本项目明确不做无缝大地图"的口径**——该否决由人在 2026-11-21 裁决推翻。

## 背景（Context）

G0–G7 已全部由人验收通过，交付的是"固定骨架 + 种子区块 + 能力门 + 收集闭环"的技术验证原型。窗口里看到的是 8×8 分区块、按数字键传送、纯色地形格；用户 2026-11-21 明确表达这不是他想要的开放世界，并在给出的三个选项中**选择第 3 项：「推翻 ADR-001 重做真正的开放世界」**。

原 ADR-001 否决无缝大地图的理由是「区块/状态边界耦合，存档、测试、确定性都变复杂，是 AI 最容易写崩的形态」。本 ADR 不否认该风险，而是**接受风险并要求用新的架构边界重新解决它**：随机仍单一来源、状态仍纯函数转移、能力门仍查表，只是把"地图"从离散区块改为连续坐标。

## 决定（Decision）

1. **连续世界坐标**：世界是一张由种子派生的连续地形网格，玩家用连续坐标 `(x, y)` 自由走动，相机视口跟随，**取消数字键分区块传送**。地形连片（草原 / 湖泊 / 浅滩由确定性 value-noise 派生），不再是每区块独立的散点色块。
2. **确定性不变量不变**：地形采样只走 `rng(world_seed, ...)`，同种子同坐标逐格一致；无裸随机、无时钟。新模块放 `src/gen/overworld.py` 等已登记扫描根，过 R0–R7。
3. **骨架仍来自受保护三表**：7 个区域作为**地标节点**落到世界固定坐标（坐标由表序 + 世界尺寸派生，不写死 region id）；能力门位置由 `topology.json` 的 `edges[].requires` 派生，代码零能力名字面量（R3）。三张表 / MANIFEST / golden 快照**零改动**。
4. **增量新增、不毁已有**：G0–G7 的代码、253 用例、CLI、报告入口保持原样继续全绿；开放世界是新增层（`src/gen/overworld.py`、`src/world/explore.py`、`src/view/overworld_view.py`、`src/ow_main.py`），双击 exe 改走新入口。旧入口 `python -m src.main --window` 仍可用。
5. **遭遇 / 捕捉 / 图鉴复用 G2**：连续地图上按种子触发遭遇，物种从当前地标的 `pool` 派生，战斗与捕捉复用 `src/world/battle.py` 的纯函数，捕捉结果经 `game.observe` 进图鉴；不重写公式。
6. **键位提示修复**：底部提示按可见宽度折行完整显示，解决"不知道怎么玩"。

## 被否决的备选及原因（Alternatives considered）

- **改三表加"世界尺寸 / 地标坐标"字段** —— 否决：受保护数据须逐次人确认，本次授权未含改表；坐标由表序 + 常量派生即可，避免重建清单 / 重拍快照。
- **抹掉 G0–G7 重写** —— 否决：已验收成果是其价值本身，且 253 用例是全绿基线；新增层隔离风险，可回归验证"旧世界没被碰坏"。
- **用 `random` / `time` 做连片噪声** —— 否决：撞 R1；用坐标派生的确定性 value-noise 替代。

## 后果（Consequences）

- 正面：真正可自由走动的连续世界；确定性、查表门控、纯函数转移三条不变量保住；G0–G7 不受影响。
- 负面：本设计只对当前链式拓扑成立（分叉 / 环路仍未实测，S3-02 延续）；开放世界美术仍是程序生成色块 + 几何图形，非商业级素材（S7-02 延续，但连片地形比散点色块显著改善）；世界规模受窗口 / 性能约束，不做无限流式加载。
- 后续注意：地标坐标 / 世界尺寸是代码常量（非 A11 数值），如人要调须另记；改地形派生逻辑不得影响 `generate_chunk` 的 golden 快照（R7 锁定）。
