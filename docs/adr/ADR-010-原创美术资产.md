# ADR-010：原创美术资产（G8 / S8-01 点名返工）

> 意图层记忆。本 ADR 是对 `ADR-009` §后果中 S8-01「开放世界美术仍是程序生成色块」的正式处置：2026-11-21 人明确点名「感觉还是太简陋了，美术一点都没有啊」，选定「原创精灵 + 场景增强」并要求改完再验收。

## 背景（Context）

G8 首次交付的连续世界在机器层面成立（`ow_report G8-demo complete=true`、263 用例全绿），但窗口仍由 `src/view/overworld_view.py` 的纯几何指令绘制：地形填 4 色、地标三角形、玩家圆头矩形身、潮灵椭圆加两个白点。人试玩后判定观感不达标，构成 **G8 验收不通过并点名 S8-01**，不是 B 组可延后观感项。

项目自 G0 起坚持零外部素材（不变量 #7：「生物名称 / 造型 / 音乐 / 文案禁用第三方 IP 素材；每个资产必须在 GDD 溯源表登记后才可入库」）。因此美术升级不能"随便找图"，必须走原创生成 + 逐项登记的路径。

## 决定（Decision）

1. **原创资产优先**：角色、8 只潮灵、7 个地标、地形 tiles 一律用原创生成工具产出，禁止取材任何既有游戏 / 动漫 / IP 造型；不使用第三方图片库、音频库、字体文件。
2. **逐项登记溯源**：每个入库资产在 `docs/GDD-v0.md` §6 原创性溯源表登记「资产 / 来源（生成工具 + 提示词要点）/ 商用授权 / 状态」，保持 R5 对 8 潮灵逐行核对的格式不变；AI 生成工具的型号 / 版本如实记录，商用政策标「待核」，不自作法律判断。
3. **资产与代码分离**：图片落 `assets/` 目录，渲染层只按稳定名加载；无资产 / 依赖缺失时优雅降级回原几何绘制，不破坏 `headless` 与四道门。
4. **确定性不受影响**：资产是静态只读资源，不进入 RNG 流、不读时钟、不改 `Explore` 状态；动画相位仍由帧计数驱动（R1）。
5. **受保护数据零改**：三张 `data/*.json` / `MANIFEST.sha256` / golden 快照一行不改；美术资产不写进表（能力 / 物种数值仍以表为唯一事实源）。
6. **打包进双击 exe**：`tools/build_exe.py` 把 `assets/` 纳入 datas；冻结态由 `sys._MEIPASS` 解析资源根，双击与源码运行显示一致。
7. **验收不被推定**：本 ADR 只完成点名项改造；改完仍需人重新验收 G8，AI 不自判通过。

## 被否决的备选及原因（Alternatives considered）

- **去找免费 / 商用素材图** —— 否决：不变量 #7 要求原创 + 溯源，第三方素材的授权链与近似风险 AI 无法穷尽，且人已裁定商标风险自担、不做检索。
- **只做纯程序化细节强化** —— 否决：人明确选「原创精灵 + 场景增强」；纯代码画图正是 S8-01 被点名的现状。
- **把美术资源写成表内字段** —— 否决：受保护三表须逐次人确认，本次授权未含改表；静态资产放 `assets/` 即可。
- **随包分发第三方字体** —— 否决：许可证义务待核，继续用系统字体候选 + 内置字体回退（S5-05）。

## 后果（Consequences）

- 正面：窗口从几何示意变为有原创美术的场景；资产来源可逐项追溯；双击 exe 与源码运行观感一致；零改表 / 零重拍 / 零裸随机。
- 负面：新增 `assets/` 二进制资源使仓库与 exe 体积增大；AI 生成内容的商用政策「待核」如实登记（自用不上架，风险由人接受）；动画仍是帧计数驱动的轻量切换，非骨骼 / 逐帧大动画。
- 后续注意：新增资产入库前必须先补 §6 溯源登记；替换 / 删除资产须同步更新溯源表；不改 R5 对 8 潮灵的结构化逐行核对格式。
