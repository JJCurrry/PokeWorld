## 模块级不变量（按需、从严）

- `src/gen/`（血肉层）：禁止 import 渲染层、禁止写模块级可变状态 —— 原因：保证纯函数与可测性。证据：G1 `src/gen/rng.py` / `chunk.py` 只放不可变常量与函数；`tests/test_golden_seed.py::TestPurityAndBounds`。
- `src/world/`（骨架层）：只读加载数据表，禁止在运行时改写拓扑 —— 原因：作者意图归人。证据：G1 `src/world/topology.py::Topology`；`tests/test_golden_seed.py::test_generate_chunk_does_not_mutate_tables`。
- `src/battle/`（战斗层）：状态与规则快照必须是 frozen 不可变值，`step` 用 `dataclasses.replace` 返回新对象；**禁止把可变 `Stream` 传进 `step`**（会破坏同参重跑），禁止模块级可变赋值与 I/O —— 原因：不变量 #4。证据：`tests/test_purity.py`（冻结实例 / 表与权重未变 / 等价上下文重放 / AST 无 assert 无 I/O 无时钟 / 模块级只放不可变字面量）。
- `src/`、`tools/`：禁止用 `assert` 承载校验（`python -O` 会剥离）—— 证据：`tests/test_schema.py::test_production_code_contains_no_assert`；一律用 `src/schema.py::must`。
