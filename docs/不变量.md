# 不变量清单（红线 · Invariants）

> 不变量 = 任何改动前后都必须为真的性质。违反后果是「事故」（存档损坏 / 世界不可复现 / 侵权 / 进度锁失效）。
> 只装「出事」的，不装「难看」的（难看的归 lint）。全局 ≤20 条；格式：对象 + 必须/禁止 + 可判定 + 原因。
> 每条都附「证据（符号）」。已落地的指向真实符号；标「未来符号」的是计划中的测试 / 模块，**当前不存在**；禁止编造符号。
> 初版缺陷见 `docs/评审/G0-冷眼.md`；**G0-R 第一轮复评结论为「不通过」**，见 `docs/评审/G0-R-复评.md`（文末附实现者处置记录）。
